# Módulo Produtos

## Objetivo

O módulo Produtos será a base para controle comercial, estoque, compras, vendas, ordens de serviço, financeiro e fiscal.

## Escopo inicial

- Cadastro de produtos
- Categorias
- Marcas
- Unidades de medida
- Código interno
- Código de barras
- NCM
- Preço de custo
- Preço de venda
- Estoque mínimo
- Estoque máximo
- Situação ativo/inativo
- Integração futura com estoque, compras, caixa, financeiro, fiscal e ordens de serviço

## Decisão de arquitetura

Será utilizado um modelo comercial/profissional, evitando um cadastro simples demais que poderia gerar retrabalho nos próximos módulos.

## Integrações futuras

- Estoque
- Ordens de Serviço
- Compras
- Caixa
- Financeiro
- Notas Fiscais
- Relatórios
